# Changelog — linkedin-preview

## 0.1.1 — 2026-10-03
Desktop app fixes from a real Code tab test: the draft tabs wrap in a narrow pane, and "See more" shows only when the draft is folded.

First release. Pane with the feed fold on mobile and desktop (3 lines, measured on the live feed in October 2026), one tab per draft, character count, markdown checks and a clean copy. Needs Claude Code 2.1.287 or newer.
